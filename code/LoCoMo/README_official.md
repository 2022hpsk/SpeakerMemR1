# LoCoMo Dataset Reference

The LoCoMo benchmark is a public long-term conversational memory evaluation
set. The original data file is not included in this artifact.

- Repository: https://github.com/snap-research/locomo
- Paper: https://github.com/snap-research/locomo/tree/main/static/paper/locomo.pdf
- Expected data path: code/LoCoMo/locomo10.json

Download the public release and place the JSON file at the documented path
before running the LoCoMo evaluation script. See DATA_SOURCES.md for the
artifact-level placement note.
