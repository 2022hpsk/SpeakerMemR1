# RL/LLM Comparison Results

This directory contains the complete SocialMem held-out comparison run used in
the Writer analysis. `units.txt` and `questions.txt` record the selected
networks and question filter; `run.log` and `compile.log` record execution;
`results/summary_speakermem_socialmem.json` contains the aggregate counts; and
`results/socialmem/` contains the question-level JSONL outputs.

The run contains 305 questions and reports 218 correct answers.
