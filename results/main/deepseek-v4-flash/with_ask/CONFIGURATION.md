# Evaluation Configuration

This directory contains the final benchmark summaries and question-level
records for the ASK-enabled SpeakerMem evaluation.

- Retrieval and answer generation use the configuration described in the
  paper and the included evaluation scripts.
- The three benchmark totals are:
  - SocialMemBench: 669/1031
  - EverMemBench-Dynamic: 1485/2400
  - GroupMemBench: 357/745
- The raw SocialMemBench records are under socialmem/.
- The GroupMemBench and EverMemBench totals are represented by their summary
  JSON files.
