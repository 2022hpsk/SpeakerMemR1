# GPT-5.6-Luna baseline results

This directory contains the baseline results for GPT-5.6-Luna across various retrieval methods.
- A-MEM, Mem0, HippoRAG, BM25, and dense retrieval include GroupMemBench,
  SocialMemBench, and EverMemBench metrics.
- The full-context baseline is available for SocialMemBench.
- The six `summary_*_qa.json` files are the question-level aggregate summaries
  for BM25 and dense retrieval.
